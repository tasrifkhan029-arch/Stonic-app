# Stonic Android quick start

This repository includes a Google Colab notebook for running the Stonic command-line agent from an Android browser. It asks for your Gemini API key using hidden input, downloads the agent script, and starts it in the temporary Colab runtime. The key is not written into the notebook.

## Open in Colab

After this branch is merged into `main`, open:

[Open Stonic Android Quickstart in Google Colab](https://colab.research.google.com/github/tasrifkhan029-arch/Stonic-app/blob/main/Stonic_Android_Quickstart.ipynb)

In Colab, tap **Run** on each code cell in order. Enter the Gemini API key only in the hidden prompt. Do not paste the key into GitHub, notebook text, or chat. If you do not have a Gemini key, create one in [Google AI Studio](https://aistudio.google.com/app/apikey). Revoke and replace any key that was previously shared or committed.

The notebook runs in Google's temporary Colab runtime, so an internet connection and Google account access to Colab are required. Runtime availability and Gemini API quota are not guaranteed. This notebook is not yet available from the `main` branch until the proposed branch is merged.
